# DSA0501 – Comprehensive Data Exploration, Analysis and Visualization

Python Pandas and Matplotlib assignment covering data importing, cleaning, joining, grouping, filtering, statistics, correlations, outliers, basic and advanced visualization.

## Run
pip install -r requirements.txt
python main.py

## Dataset
Synthetic datasets generated with NumPy/Pandas for educational and reproducible demonstration.

## Outputs
CSV datasets are saved in `data/`; charts and analysis outputs are saved in `results/`.
